### [TrafficPulse](https://github.com/Kisara00555/trafficpulse) · Hourly traffic forecasting

AI-assisted learning project. The pipeline checks missing hours and duplicate timestamps, builds lag features, and tests for leakage before evaluating forecasts in time order.

| Weekday/hour baseline | TrafficPulse model | Historical holdout |
| :---: | :---: | :---: |
| 272.9 vehicles/hour MAE | **185.6 vehicles/hour MAE** | 6,533 observed hours at one I-94 station |

**32.0% lower mean absolute error** on the Jan–Sep 2018 holdout. The demo replays historical forecasts, and interval coverage varies by hour. [Read the evaluation](https://github.com/Kisara00555/trafficpulse/blob/main/docs/HOLDOUT_RESULTS.md)
